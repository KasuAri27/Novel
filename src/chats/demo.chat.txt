# =====================================================
# 聊天模式示例剧本（格式演示用，可删）
# 完整格式说明见 docs/chat-format.md
# =====================================================
@story id=chat_demo title=停电的夜里
@entry start

# ---- 角色 ----
# me = 主角：她的台词和玩家选的回复都在右侧气泡
@char 我 me
@char 林夏 color=#d0607a
@char 宿管 name=宿管阿姨 color=#3f8fb8

# ---- 事实（信息差：谁知道了什么） ----
@fact 林夏在等电话

# --------------------------------------------------
@node start
> 晚上十一点，整栋宿舍楼的灯一起灭了。
> 窗外只剩下对面楼零星几格应急灯，绿幽幽的。
林夏> 啊——我的论文！！
林夏> （扑到桌前狂按电源键）没保存……我没保存……
我> 先别急，笔记本不是有电池吗？
林夏> （愣住）……对哦。
> 屏幕亮了起来，她长长地出了一口气，又盯着手机发呆。
[choice] 你今晚怎么一直看手机？ -> ask
[choice] （递给她一杯温水） -> water
[choice] 【先去走廊看看情况】 -> hall

@node ask
林夏> （把手机扣在桌上）没什么。
林夏> ……在等一个电话而已。
[enter] do know(我, 林夏在等电话)
[goto] hall

@node water
林夏> 谢啦。（捧着杯子，指尖还有点抖）
林夏> 其实我刚才不全是因为论文慌。
[goto] hall

@node hall
> 走廊里传来拖鞋啪嗒啪嗒的声音，一束手电光扫过门缝。
宿管> 都别乱跑啊！电工在修，半小时就来电！
> 手电光远去了。林夏的手机屏幕亮了一下，又暗下去。
[choice] 是他打来的吗？ -> call when knows(我, 林夏在等电话)
[choice] 要不我们点根蜡烛聊聊天？ -> talk
[choice] （假装没看见，翻身睡觉） -> sleep do set(装睡, true)

@node call
林夏> （猛地抬头）……你怎么知道是「他」？
我> 猜的。你刚才自己说在等电话。
林夏> 是我爸。他住院了，今晚做手术。
> 她说完这句，像是终于把什么重东西放了下来。
[goto] fin

@node talk
林夏> 好啊。（摸出抽屉里的生日蜡烛）只有这个，凑合吧。
> 小小的火苗在两人之间晃着，墙上的影子被拉得很长。
[goto] fin

@node sleep
> 你闭上眼。黑暗里，听见她很轻地叹了口气。
[goto] fin

# 路由节点：没有正文，只用 ▸ 自动分支（玩家看不到，按顺序取第一个满足的）
@node fin
[choice] ▸ -> fin_alone when flag(装睡)
[choice] ▸ -> fin_light

@node fin_light
> 零点十二分，灯回来了。
林夏> （手机响了，她看了一眼，笑出声）手术很顺利。
林夏> 今晚谢谢你陪我。

@node fin_alone
> 零点十二分，灯回来了。
> 你翻了个身，看见她还坐在桌前，屏幕的光照着她没有表情的脸。

# ---- 结局：走到没有出口的节点时，按条件与 priority 结算 ----
@end lonely priority=10 when flag(装睡)
title 各自的夜晚
text 有些话，错过了那个停电的晚上，就再也没机会问了。

@end together priority=0
title 烛光
text 后来林夏说，那是她大学四年里最难熬、也最不孤单的一个晚上。
