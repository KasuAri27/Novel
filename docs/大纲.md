## 0. 架构总纲

- **完全取代**旧 A/B/C/D 分型树与五格结局，改用「**第一案结果 × 信任值**」的结局判定。
- **信息差仍是唯一的底层规则**：所有限度判定、案件是否发生、信任涨落，都由「各角色知道什么/不知道什么/以为什么」的信息差驱动。
- 结局走向只受**几个关键点**支配：
  1. **第一案的结果**（不发生 / 希罗死 / 梅露露死 / 诺亚×蕾雅死）
  2. **梅露露信任**
  3. **希罗信任**
- 这几个关键点在结构上锚定结局，但它们的数值完全由**选择产生的信息差**累积而来——结构简化了，因果没有退化。

### 三层阶段
```
阶段① 铺垫章（ch1–3，零案件，压力播种）
     ↓ 三对冲突化解度 + 两把信任尺（信息差累积）
阶段② 第一案判定（ch4）
     ↓ 第一案结果
阶段③ 终局链（后续案件收束 + 信任值结算）→ 终局
```

## 2. 阶段①　前三章 · 铺垫章（零案件，压力播种）

> 前三章不出现案件，只埋隐患、演冲突、累积信任。玩家通过每一章的选择，架设/阻止信息的流向。

### 2.1 三对冲突

| 冲突对 | 本质 / 成因 | 玩家的对角任务 |
|---|---|---|
| **艾玛 ↔ 希罗** | 希罗坚信「艾玛害死了雪」（艾玛-希罗开局冲突） | **动摇**——用选择撬动希罗的认知，让她开始怀疑「艾玛是凶手」是否真实；**不需要完全和解**，只要怀疑松动 |
| **梅露露 ↔ 玛格** | 梅露露**过度关照玛格**，而玛格的禁忌是「**不能被爱**」 | **双阀门**：① 阻止奈叶香用魔法探查真相（防她发现梅露露是幕后黑手）② 阻止梅露露踩玛格禁忌（别过度关照） |
| **诺亚 ↔ 蕾雅** | 注目与被注目（蕾雅需要被看见，诺亚画的《队长》把注目归还给蕾雅） | 惯注化解与否——**这对钦定第一案主角** |

**分解：梅露露的两把刀（信息差决定）**
- 玩家**放任**奈叶香探查 → 奈叶香发现梅露露是幕后黑手 → 奈叶香杀梅露露
- 玩家**阻止**了奈叶香、却没化解梅露露↔玛格（或没保护梅露露落单）→ 玛格穷凶杀梅露露
- 两条路都指向梅露露死亡，但凶手不同、凶手存活与否不同——终局也随之分叉。

### 2.2 两把信任尺（前三章选项累积）

| 尺 | 定义 | 累积方式 |
|---|---|---|
| **梅露露信任** | 梅露露对艾玛的信赖 | 前三章各化解点选项 → 尤其「是否保护她/是否尊重她而非过度关照」 |
| **希罗信任** | 希罗对「艾玛是凶手」的执念松动度（≠亲密值） | 前三章各化解点选项 → 动摇希罗认知的**信息投放** |

> 注意两把尺**不对称**：梅露露尺是「信赖」，希罗尺是「怀疑松动」。希罗尺走得慢、且可被终局期的「合照」一次性补足（见 §4）。

### 2.3 预期的章内落点（初拟）

- **ch1**：世界观投放＋群像只特写核心；艾玛↔希罗露头；梅露露↔玛格初见。
- **ch2**：诺亚↔蕾雅登场＋艾玛首轮调解尝试＋奈叶香探查线的首个选择岔口。
- **ch3**：冲突总清算前夜；化解度与两把尺累积收官，铺向第一案判定。

## 3. 阶段②　第四章 · 第一案判定

由前三章化解度（＝信息差结果）路由：

- **三对冲突全解**（诺亚蕾雅不爆＋梅露露双阀门守住＋希罗被动摇未引爆）→ **第一案不发生** → 全员存活线。
- **某对未解** → 该对引爆 → 第一案按未解对象分化：

| 未解的对 | 第一案形态 | 死者 |
|---|---|---|
| 希罗被动摇失败而引爆 | 希罗魔女化加重→挑战守卫→被守卫反杀（**无审判**，插曲式死亡） | 希罗 |
| 梅露露双阀门失守 | 奈叶香的刀，或玛格的刀 | 梅露露 |
| 诺亚↔蕾雅引爆 | 标准案（受害者＋处刑凶手互杀） | 诺亚、蕾雅 |

## 4. 阶段③　终局树

```
第一案结果
│
├─ 不发生（全员存活）
│     花约 2–3 章取得希罗+梅露露完全信任
│     ├─ 取得梅露露信任 → 探索线
│     │    ├─ 取到【合照】(→希罗得知真相/恢复记忆 → 瞬间取得希罗信任)
│     │    │     └─ 再加【安息仪式信息】→ 召唤雪 → 终章·与雪辩论
│     │    │           ├─ 雪和解 → 完整 HE
│     │    │           └─ 雪杀戮 → BE
│     │    └─ 未取到合照 → 探索失败 → 落回生活线
│     └─ 未取得 → 生活线（后段选项只关乎信任，结局按信任分化）
│           ├─ 都未取得 → 艾玛+雪莉+汉娜小团体亲近；梅露露、希罗双疏远
│           ├─ 单取得 → 对应角色贴近（取得者），另一方保持距离
│           └─ 都取得 → 完美生活线：艾玛×梅露露×希罗三人亲近和睦
│
├─ 希罗死（挑战守卫被反杀，无审判）
│     → 存活：艾玛+梅露露
│        梅露露信任高 → 二人合作生活
│        梅露露信任低 → 梅露露妄图杀艾玛 → 艾玛魔法觉醒 → 清场 BE
│
├─ 梅露露死（奈叶香的刀 / 玛格的刀）
│     → 存活：艾玛+希罗
│        希罗信任高 → 二人生活
│        希罗信任低 → 希罗妄图杀艾玛 → 艾玛魔法觉醒 → 清场 BE
│
└─ 诺亚×蕾雅死（标准案：受害者+处刑凶手）
      → 存活：艾玛+梅露露+希罗
         梅好希好 → 三人生活
         惟希低 → 梅露露护艾玛而杀希罗
         惟梅低 → 希罗杀梅露露
         双低 → 梅露露与希罗同归于尽
```

### 4.1 BE 统一机制（不再依赖仪式失败）

低信任方**妄图杀死艾玛** → 触发 **艾玛「魔女杀手」觉醒**（可秒杀全岛）→ 清场，全员死亡。被玩家亲手放弃的人，逼迫艾玛变成毁灭者。

### 4.2 雪线的唯一入口

雪线只存在于「**全员存活 → 探索线 → 合照 → 安息仪式信息**」这条路径；**雪只在仪式后现身**（硬约束，延续旧设定）。第一案只要发生，任何分支都无雪线——雪是可贵的完美操作奖励。

### 4.3 探索线的触发与门钥（已确认 2026-09-04）

- 触发前置：**梅露露信任**达标。
- 探索空间：**图书馆**＋**地下室**，搜索安息仪式相关信息。
- 梅露露参与度随信任与选择浮动：可**与梅露露合作**探索，或**梅露露默许**你们自行探索（两种强度）。
- 由物证（合照、仪式信息）推进至召唤雪 → 终章与雪辩论。

## 5. 阶段③·续　后续案件机制（**已确认 2026-09-04**）

> 第一案确立后，故事转入「**冲突驱动**」轨道。核心存活组合由第一案锁死，中段案件只负责清出组合外角色、并把信任推到终值。

### 5.1 已确认的硬规则
1. **核心免疫**：梅露露（幕后黑手、全知能驱使管家）、希罗（超前能力）是能力核心。**只要第一案没死，后续案件绝不阵亡**（有能力自保）。唯一死路：①第一案出局 ②终局树的互杀（护艾玛杀希 / 希杀梅 / 同归于尽）③BE 清场。中段案件杀不动她们。
2. **中段＝一直杀到只剩终局所需存活组合为止**；组合一成立即入终局（章节数自然浮动，不硬编）。
3. **奇偶性**：每案标准出局 2 人（受害者＋处刑凶手）；「艾玛+希罗」线（希罗存活、梅露露死）人数呈奇数，**最后一案需双杀**来补整；「希罗死」线因守卫反杀案只出局 1 人，自动凑整则不双杀。
4. **冲突节奏（不可逆但有窗口）**：
   - 第一案发生 → 杀戮不可逆，但整条线**最多拖两个章节**再继续杀人。
   - **每一章必须有一个活跃冲突**。
   - 第四章＝第一案发生＋新冲突A；若处理得当（无案），第五章出现冲突B。
   - **冲突不可完美解决，只延迟爆发**；一个冲突最多被拖两章，两章后必然引爆成案；没处理好则下一章直接爆。
   - 已走完的冲突不回头，但"延迟"不取消——**一个冲突最多扛两章**。

### 5.2 展示手法（模仿原作，已确认）
- **表层冲突 ≠ 真正冲突**。原作第一案：对玩家展示的是「诺亚↔安安」的冲突，**实际真冲突是「蕾雅↔诺亚」**。
- 写作要求：**不把真正的冲突摆上台面**，只演表层，让玩家根据**角色性格**去分析到底谁与谁冲突、去挖深层。玩家的"推理"＝在文字分析里找信息差。
- B 确认：中段凶手/受害者**全然由信息差＋信任尺自由演化**——冲突由信息差不自然地浮现，玩家透过文字分析信息差、定位真正的冲突双方。不做死板的"死亡队列"（可给玩家可读的信号，如雪莉的规律推理扶手，但生成全看信息差）。

### 5.3 章节冲突容量（已确认）
- **一章只能有一个活跃冲突**。
- **冲突的解决＝拖延**：把一个冲突"解决"＝把它往后推 **2 章**（期间内持续铺陈、玩家可用选项缓解）。
- **第二案分水岭（已确认 2026-09-04）**：累计发生第二案之后，**冲突无法再被解决/拖延，必然点燃成案**（"解决"选项失效）。c≥2 即进入不可逆收割期——这解释了"c≥2 每章必案"的机制根因，而非规则硬凑。
- **诺亚×蕾雅（残留暗雷）位次（已确认 2026-09-04）**：这对若未成为第一案（第一案死于希罗或梅露露），则**固定延迟到第六章，直接作为冲突A爆发**——不随其他中段冲突错位，独立占用第六章。
- **第四章＝第一案＋审判主章（已确认 2026-09-04·修订）**：第四章以**第一案＋众人首次面对案件与审判**为主，**不新增信任选项**。前三章的信任收集在第四章**文本层兑现为节点差分**（靠开场状态，不靠本章选项）：
  - 希罗尺＝**完全动摇／未完全动摇**两节点；未完全动摇→她仍坚信艾玛害死雪→第一案走向希罗魔女化→被守卫反杀。
  - 梅露露尺同理（信任/动摇两节点，决定其第一案死向其与后续走向）。
  - 第一案的对象仍由前三章冲突解决度判定。
- **第四章·信任收集**：信任获取只发生在**前三章**（铺垫章内通过选项累积两把尺），第四章起只"兑现"不再"收集"。
- **双案叠加**：当"拖着的旧冲突"与"该章新冲突"同时临爆——若冲突A被避免、冲突C（第六章）爆发，则**第七章发生两案**：先爆冲突C，再爆冲突A，两案之间用**小段文字过渡**（一处审判、两宗死亡）。

### 5.4 双杀形态（已确认）
终案双杀＝凶手**连杀两人**：第一人因冲突被杀（有动机），第二人**只是不小心被牵连进来**（殃及池鱼）。认定的元凶仍处刑；被连坐者是无辜受害者。

### 5.5 冲突表（作者私有机制，对玩家与正文隐藏）

- 采「冲突表」作为底层秩序：每条线预先构造"最早出场的冲突配对＋各自可拖延数"。
- 但**具体"谁对谁"为作者私有设计**——不写入玩家可见设定，也不在讨论中展开。
- 写作规则：真冲突以**表层伪装**呈现（§5.2）；玩家经选择→信息差→**解决 / 无效 / 引爆**冲突。
- 冲突构成由信息差自由演化，冲突表只提供骨架；正文永远只演表层。
