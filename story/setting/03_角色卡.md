**原罪**：空想千金 ｜ **魔法**：飘浮（觉醒前：微浮数厘米数分钟且很累；觉醒后：大量物体飘浮）｜ **创伤**：抛下离开·被弃于原地（双亲抛下婴儿离开，最年幼的妹妹因自己能力不足而死）｜ **禁忌**：【待验证】暂定：贫穷的谎言/自卑被当面戳穿

**五维卡**

1. 基本身份：陶瓷娃娃般娇小削瘦的金发双马尾，自称名门千金。言行处处破绽的大小姐腔（"～的说/～哇"），被指出矛盾立刻吵架。
2. 核心性格：大小姐是自学演技——出身众多兄弟的贫困家庭，靠努力背下千金举止；架子与口无遮拦是伪装，本质坦率、为人着想；对敞开心扉的人流露毫无掩饰的温柔（缝纫手艺是真的，衣服真的自己做）。
3. 灵魂场：①大小姐演到底（那是她的梦想与尊严）②被指出破绽必反击 ③被单独留下=雷（抛弃创伤）④对真心朋友付出不求回报。
4. 语言指纹：大小姐腔+不经意露出的粗俗词；吵架时演技全崩；夸人时会突然真诚得吓人。
5. 关系网：雪莉（官配：给她"若我魔女化请杀了我"托付的人——本线这层羁绊的变体由大纲决定）；蕾雅（原作她因蕾雅无心之言崩溃杀了她——**"家境话题"是这组关系的历史地雷**）。

**二创引擎**

* 初始信息状态：普通不知情位+贫穷秘密。

* 创伤引擎：贫穷/寒酸话题；大小姐设定被质疑；被单独留下（"你们先走不用等我"对她是酷刑）。

* 安抚手段：配合她的演技但不拆穿；真心夸她的手艺；任何场合都不留她一个人。

* 魔女化信号：轻——大小姐腔破绽变多；中——缝纫到深夜、对"穷"字反应过激；重——**开始坦白童年**（她放下演技=放弃伪装=临界，这是她独有的倒转信号：坦白不是治愈是失控）。

* 设计定位："真诚与崩坏一线之隔"的角色。她的坦白信号是给老玩家的专属恐怖——不懂的人以为终于交心了，懂的人已经开始害怕。

### 泽渡可可（编号 669）

**档案**：15 岁 / 8 月 8 日 / 狮子座 / 158cm·50kg·B 型 / 成绩：下 / 第一人称：人家（あてぃし）第二人称：你这家伙（あんた/てめぇ）/ 兴趣：游戏动画漫画全部亚文化 / 特技：电脑 / 喜欢：追星应援 / 讨厌：除自推与自己以外的世界上的一切 / 家庭：祖父 / 梦想：世界第一主播，让自推比谁都幸福
**原罪**：孤独的直播主 ｜ **魔法**：千里眼（觉醒前：当自己被看着（画像照片皆可）时，能以监控视角俯瞰对方状况；觉醒后：越过次元界限）｜ **创伤**：捉迷藏（家人被杀时独自躲藏，通过魔法亲眼目睹全程）｜ **禁忌**：【待验证】暂定：躲藏情境再演

**五维卡**

1. 基本人份：小主播（微薄收益），黑发+猫耳耳机+赛博朋克装。配信时开朗积极，实际憎恨世界上一切，毒舌刻薄的麻烦制造机。口癖"恶心（キモ）"。
2. 核心性格：表里反差极大；主张强、引人注目；本性不正派，会凑近讨好对自己有利的人（狡猾）；但谈"推し"时会露出恋爱中少女般的纯真——**推し=爷爷**（很少有人发现真相）。
3. 灵魂场：①毒舌是呼吸 ②推し至上 ③对有利者贴、对无用者踩 ④被看见既是创伤也是武器——她主动暴露于人前，用厌恶武装自己。
4. 语言指纹：主播腔+网络用语（"绝了""下头""恶心"）；情绪一坏立刻阴阳怪气；谈爷爷时声音软三度。
5. 关系网：亚里沙（亚文化同好吵架友【二创可发展】）；爷爷（唯一的救赎与软肋）；观众（她真正的"人际"——没有观众=没有她）。

**二创引擎**

* 初始信息状态：普通不知情位+断网主播的戒断反应（开局她最躁——"没信号"是她的持续压力源）。

* 创伤引擎：没有网络/观众的世界（存在根基被拔）；被无视（没人在乎她的配信）；躲藏类游戏/情境（捉迷藏=家人被杀现场）。

* 安抚手段：当她的观众（听她讲推し、陪她游戏）；给她"舞台"（哪怕是给几个人表演吐槽）；聊爷爷话题的分寸要精准。

* 魔女化信号：轻——毒舌升级、无意识敲击不存在的键盘；中——把自己关进房里对着不存在的镜头说话；重——把某人认成"该杀的坏人"（家人被杀现场的投射）、"除了爷爷全都是恶心东西"的排除宣言。

* 设计定位：压力计与搞笑役的双重身份。她最先闹、最先躁，是"环境压力"的可读仪表盘；同时她的千里眼（需画像条件）是可设计的信息获取装置。

## 管家与守卫（NPC）

* **管家**（原作典狱长·猫头鹰，CV 中尾隆圣）：表面运营者。到点下班、讨厌加班、不乐见案件（工作量+）。偶尔以抱怨的方式漏信息（"又要开审判了，加班费可没有哦"）。实际是梅露露的使魔。

* **守卫**：异形们。真实身份=魔女化后被洗脑的前收监少女。众人的表面认知=宅子的诡异仆役。其中一只是**奈叶香的姐姐**。二创职能：阻止逃跑、维持秩序；第一案发生后执行审判的相关运营。
