# 核心机制（二创引擎）

> 信息差引擎 · 魔女化压力模型 · 雪线观测 · 审判流程 · 结局判定
> 本文档是互动小说的"游戏规则"层，写章节大纲与选项树时必须对照本文。

## 一、信息差引擎（总纲）

**剧情的唯一驱动力是信息：每个角色知道什么、不知道什么、以为什么。**
不使用任何数值属性；角色状态全部以"信息池"描述。

### 1.1 三层信息结构

```
玩家（上帝视角，通过艾玛的眼睛看世界，但只能看到艾玛能看到的）
  ↓ 选项 = 艾玛的行为
艾玛（视角角色：她的所知、所想、误解）
  ↓ 艾玛的行为被他人观察
各角色信息池（谁知道什么——含误解与错误信息）
  ↓ 钢笔持有者的所知被雪同步观测
雪（暗线：她的所见决定她的心证）
```

* 玩家的每个选项 = 一次信息投放：向某个角色（含艾玛自己）的池子里注入信息、误解或悬念。

* 信息差的方向决定剧情性质：

  * **读者＞角色**（读者知道角色不知道的雷）→ 悬念（"别问她那个问题啊！"）

  * **角色＞读者**（某角色藏着秘密）→ 谜团（探索动机）

  * **角色 A 以为 X，角色 B 以为 Y** → 冲突燃料（信息差碰撞 = 矛盾爆发 = 魔女化加速）

### 1.2 信息池的追踪

每个角色（含雪）维护一份状态：**已知事实 / 错误认知 / 不知道的关键信息 / 情绪基线**。
章节写作时同步更新（状态文件另建，见长篇管理）。初始矩阵由角色卡"初始信息状态"推导。

### 1.3 选项设计原则

* 选项不写"好感度±"，只写"谁因此知道了什么/以为了什么"。

* 每个选择都有代价方向：给某人真相可能揭另人的疤；说谎保护一个人就在两人之间埋雷。

* **信息是武器也是炸药**：揭露某人的创伤 = 给她压力（魔女化加深）；替她保守 = 给她安慰（魔女化缓解）但同时积累更大雷区。

## 二、魔女化压力模型

### 2.1 双轨触发

1. **渐进轨**：创伤被揭开/戳中 → 压力累积 → 行为信号异常 → 杀意临界 → 杀人。
2. **禁忌轨**：触碰个体化禁忌（如对亚里沙说"我原谅你"）→ **瞬间完全魔女化** → 立即杀人（大概率当场爆发，成为案件）。

### 2.2 压力源清单（= 创伤引擎）

压力完全来自**环境 + 角色自身创伤**（用户决策 Q2）。每个角色的"创伤引擎"（什么事件给她压力）与"安抚手段"（什么选择能缓解她）详见角色卡。通用压力源：

* 集体生活本身（对创伤角色是慢性毒：安安怕"变得幸福"、玛格讨厌"平稳日常"、蕾雅需要注目、可可厌恶人群）

* 未知监禁期限（"要住多久"没有答案 → 无期徒刑的想象空间）

* 岛的诡异性（异形守卫、常开樱花、常驻彩虹）

* 案件与审判（每一起案件 = 全员压力事件，魔女化整体加速 → **案件会自我催化**，越到后期矛盾越易触发）

* 玩家选择直接戳中的创伤（信息差的代价）

### 2.3 信号系统（玩家可读）

魔女化对玩家以**文本信号**呈现（用户决策 Q3），分三档：

| 程度 | 信号表现                 | 玩家可感知渠道    |
| -- | -------------------- | ---------- |
| 轻度 | 口癖变化、小动作异常（各角色卡定制信号） | 细心阅读可发现    |
| 中度 | 语气明显不对、行为越界、与他人摩擦变多  | 明显的文本描写    |
| 重度 | 杀意外露的言行、异常冷静或异常亢奋    | 艾玛的心里话直接提醒 |

* **艾玛的心里话**是兜底软提示（"总觉得她刚才的笑容，让我后颈发凉"）——保留原作"艾玛敏锐观察"的角色特质。

* 信号 ≠ 确诊：玩家可能误读（把中读成轻），误判的代价是案件发生。

### 2.4 魔女化 → 案件

* 全部案件 = 魔女化驱动（用户决策 S1，无清醒预谋作案）。

* 凶手与受害者的配对 = 信息差的产物：**谁的压力先到临界 × 冲突对象是谁 × 场景机会**。

* 魔女化杀人后的行为：凶手清醒后记得并知晓自己杀人（原作认罪逻辑），魔女化状态下可能做出本能掩饰（藏尸、误导），审判因此成立。

* **可还原性**：肉体完全魔女化前，魔女化程度可被安抚/治愈逆转。审判处刑是运营方的物理处理，玩家的"治疗"则发生在日常——**玩家的日常选择就是治疗行为**，这是本作最核心的玩法-叙事咬合。

### 2.5 雷区地图（禁忌一览）

| 角色  | 禁忌（瞬间魔女化条件）                | 状态                |
| --- | -------------------------- | ----------------- |
| 艾玛  | 对好友被霸凌视而不见（= 恢复记忆）         | 原作确认              |
| 希罗  | 自杀                         | 原作确认              |
| 梅露露 | 认为自己被大魔女抛弃                 | 原作确认              |
| 雪莉  | 认识到自己并非无血无泪的怪物，而是拥有丰富情感的人类 | 原作确认              |
| 亚里沙 | 被原谅                        | 原作确认              |
| 蕾雅  | 不被他人注视                     | 推断（NGA 玩家讨论，待验证）  |
| 安安  | 想起"不妙的回忆"（家人变提线木偶）         | 推断（待验证）           |

> 玩家不需要提前知道禁忌；禁忌通过探索与信号逐渐暴露。知道某个人的禁忌本身就是重要信息（信息池资产），可以用来自救——也可以用来杀人。

## 三、雪线观测机制（纯暗线）

### 3.1 钢笔流转

* 开局：钢笔在**希罗**身上（她习惯用它写字/记录）。

* 雪的所知 = **钢笔携带者所知**。开局雪看到的世界 = 希罗眼中的世界——而希罗恨着艾玛。**雪开局对艾玛的印象是经过希罗滤镜的**：玩家若想让雪看到艾玛的好，先要让希罗看到。

* 希罗死亡 → 艾玛取走钢笔（遗物）→ 雪的观测对象切换为艾玛，**雪与艾玛完全同知**（包括艾玛的内心）。

* 钢笔是物理物品：可以被看见、借用、抢走、损坏（原作二周目希罗掰断过钢笔）。携带者变更 = 雪的观测窗变更——这本身可以是剧情装置（如：把钢笔交给梅露露 = 让雪看到梅露露的思念）。

### 3.2 雪的心证（无数值，用"所见清单"追踪）

雪的信息池特殊：= 钢笔携带者所见 + 500 年复仇执念的先验。她不受任何数值控制，但**她的判断材料就是她看见的**：

* **看见温馨**：少女们互相扶持、创伤被治愈、梅露露复刻"与魔女共同生活"的日常 → 复仇执念被侵蚀（对应原作"美好的时光中雪的复仇心逐渐黯淡"）。

* **看见杀戮**：审判处刑、互相猜疑、艾玛的黑化苗头、希罗的"正义"暴走 → 执念强化（"果然人类/该杀"）。

* 最终章雪的抉择 = 她的所见清单加权她的自由意志。**雪的选择不可被玩家直接操控**（S4：与艾玛配合与否无关）——玩家能做的只是决定"让她看什么"。

### 3.3 雪现身的条件（待确认项 A1，推荐方案）

"存活角色对雪的探索度"操作定义为：**魔女岛历史/雪的痕迹的挖掘深度**，由特定剧情事件累积：

* 图书室的魔女相关藏书、常开樱花与常驻彩虹的真相

* 地下设施的发现

* 梅露露讲述的"与魔女共同生活的过去"（她不会说雪的名字与复仇计划）

* 奈叶香的守卫真相线

* 钢笔本身的来历

探索度不足 → 雪不现身，按存活组合进 END（雪留在钢笔里，结局不揭示她——留白型结局）。
探索度足够 → 终盘雪现身与艾玛相见 → 按雪的心证分岔和解/毁灭。

> 若用户倾向其他定义（存活人数阈值/固定剧情时点），改写本节即可。

### 3.4 艾玛的认知锁

* 艾玛**不能**通过传闻、推测、半截真相得知雪的存在——恢复记忆 = 瞬间魔女化 = 毁灭 END（原作一周目重演）。

* 唯一例外：雪当面现身 + 雪选择和解 → 艾玛得知一切而不崩溃。

* 写作纪律：任何向艾玛泄漏雪相关信息的选项都必须设计阻断（被打断、误会成别的东西、艾玛的心理防御性遗忘——她曾把雪的记忆替换成自己的，这种防御是既定心理机制）。

## 四、审判流程（可玩化）

### 4.1 循环结构（章/话单位）

```
日常（选项投放信息、观察信号、治疗或埋雷）
  → 案件发生（魔女化临界 × 信息差碰撞 × 场景）
  → 搜查（自由调查，信息收集；希罗在 MVP 中不可搜查？见角色卡）
  → 魔女审判（辩论：指出矛盾 → 反驳/赞同/疑问 → 投票）
  → 处刑（亲手选择处刑对象——仪式性高潮）
  → 余波（全员压力事件 → 新的日常，下一循环）
```

### 4.2 审判的可玩性设计

* 借用原作机制：反驳（指出证词矛盾）、赞同（确认猜想）、疑问（追问获取线索）。

* 玩家选错 → **其他角色反驳**（如蕾雅"等一下，这个结论说不通"）→ **梅露露提示**（"艾玛酱，再想想她刚才说的话……"）→ 回到选择。审判必胜，但错误选项也写足内容（原作传统：错误答案也是角色塑造素材）。

* 审判的信息学本质：**这是信息差的大清算**——凶手靠信息差藏（掩饰、误导），玩家靠信息差攻（证词矛盾 = 某人的"所知"与"事实"的错位）。

* 处刑演出：投票 → 管家宣告 → （若 A2 采纳封印设定：怪物化后封印，留恢复伏笔）→ 全员心理冲击（处刑 = 巨大集体压力事件，必然加速剩余角色魔女化——**审判的胜利从不免费**）。

## 五、结局判定矩阵

### 5.1 End 进入条件（用户原设定）

**存活角色的信息差不会再导致下一次杀戮**时进入 End。操作含义：

* 剩余角色的创伤要么被安抚（魔女化回退），要么互相知情且接纳（信息差消解）；

* 剩余组合中不存在"一戳就爆"的禁忌暴露风险；

* 否则剧情继续循环（还会有案件）——**End 不是走到终点，而是系统稳定**。

### 5.2 判定维度

1. **存活组合**（艾玛必活；其他 12 人由玩家选择决定生死）
2. **关系状态**（希罗是否和解/信任艾玛；梅露露与艾玛的羁绊；等等）
3. **雪线**：探索度（是否现身）× 心证（所见清单）
4. **艾玛状态**（未魔女化是 END 的前提）

### 5.3 结局清单（承接总纲）

* **真 HE**：全员存活无魔女化（或准 HE：中途封印者在雪和解后被恢复）+ 雪现身并和解 → 众人（+雪+梅露露）共同生活在魔女岛。

* **雪不出现的 END**：四人组合 × 关系状态的收敛解（艾玛独活 / ＋希罗 / ＋梅露露 / 三人）。独活线是玩家失败收敛的兜底（哪怕全员死光，故事仍要以艾玛的视角收尾）。

* **雪出现的分岔**：

  * 和解线：雪的心证偏向温暖 → 现身 → 与艾玛相见（艾玛得知一切但不崩溃）→ 按存活组合给团圆变体。

  * 毁灭线：雪的心证偏向绝望 → 现身收回魔法杀死所有人（艾玛存活观看 / 或"雪与梅露露共同生活、杀死艾玛"变体）。

* **艾玛黑化 END**（隐藏坏结局）：艾玛恢复记忆（认知锁被打破）→ 魔女化 → 屠杀所有人（原作一周目重演）。任何让艾玛接触雪真相的非合规路径都通向这里。

* **艾玛濒死 END**（隐藏坏结局）：某角色杀艾玛未遂/得手瞬间 → 艾玛瞬间魔女化 → 反杀 → 同上毁灭。

### 5.4 MVP 范围内的最小结局集

第一章（开局日常 → 第一案 → 审判）只实现：第一案的正确处刑（继续）/ 审判内错误重选 / （若第一案设计允许）玩家重大失误导致的即时 BE。全局 END 系统在后续章节展开。

## 六、写作纪律（机制层给创作的硬约束）

1. 选项永远描述信息流向，不描述数值结果。
2. 案件凶手必须是"信息差 × 压力临界"的必然结果，不允许随机感和"剧情需要"感——每起案件要能事后复盘出完整因果链。
3. 艾玛视角的文本永远不能超出艾玛所知（这是信息差引擎的根基；艾玛不知道的事，叙述必须留白或误写）。
4. 雪的暗线文本（钢笔的静默描写、雪的凝视感）要克制，前期玩家最好完全意识不到——reveal 时回想起来才后怕。
5. 角色禁忌一旦在剧情中被玩家得知，之后玩家的每个相关选项都自动成为生死抉择——这是设计好的张力，不要浪费。
