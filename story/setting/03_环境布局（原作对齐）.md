## 背景与基调

孤岛上一座哥特风牢狱洋宅，俗称「**牢屋敷**」。建筑物宽敞且相当破旧，许多地方散发令人汗毛直竖的气氛；中央有极宽阔的玄关大厅，连接上层的楼梯长到仰头才能望见尽头。关押少女们的「監房」位于地下——登上长长的楼梯才回到地面层。

## 二创环境铁律（写作时对照）

1. 地点用词一律用上表原作名；不自造"礼堂/旧馆/阅览室/小屋/后院"等。
2. 少女们住**地下監房**；放风时段（06:00–10:00 / 12:00–15:00 / 17:00–22:00）门开放可出入。
3. 熄灯宵禁 = **22:00–次日 06:00**（正文不得写 21 时熄灯）。
4. 岛内自然水景 = **湖**；"海"只存在于渡海登岛与远望海平线。雪相关记忆若需水景，用"湖"。
5. 雪线探索入口（図書室魔女藏书 / 樱花树 / 湖景 / 地下倉庫・控制室 / 医務室梅露露 / 奈叶香守卫线 / 钢笔来历）都落在上表场所，不得另起新地名。
